# Dify：日本語入力対応 & 例文の日本語訳

アプリ側は `example_1` / `example_2` の JSON 内 `ja` を表示します。  
LINE で日本語を送った場合も同じ形式で保存・返信するよう、Dify ワークフローを次のように設定してください。

## 1. 開始ノード

既存の `line_user_id`（必須）のままで OK です。日本語か英語かは **LLM がユーザーのメッセージ（query）から自動判断** します。

## 2. LLM ノードのプロンプト（例）

```
あなたは英語学習アシスタントです。ユーザーの入力が英語でも日本語でも、必ず同じ形式で答えてください。

【入力が英語の単語・フレーズの場合】
- word: その英語
- meaning: 日本語の意味
- 例文は英語＋日本語訳の2つ

【入力が日本語の場合（例：「〜って英語で何？」「放っておく」）】
- word: 対応する英語の単語・フレーズ
- meaning: ユーザーが聞いていた日本語（または自然な日本語の言い換え）
- 例文は英語＋日本語訳の2つ

【LINE返信（<SPLIT>区切り・最大5件）】
1. 英単語
2. 日本語の意味
3. 例文1（英語）
4. 例文1の日本語訳
5. 例文2（英語）※余裕があれば
（説明は memo に入れ、必要なら別メッセージ）

【Supabase保存用】
- word: 英語
- meaning: 日本語
- example_1, example_2 は必ず次の JSON 形式（文字列）:
  {"en":"英語の例文","ja":"日本語訳","note":""}
- memo: その単語についての日本語説明
- line_user_id: {{#開始.line_user_id#}}
```

## 3. HTTP リクエスト（Supabase POST）の Body 例

```json
{
  "word": "（LLMが生成した英語）",
  "meaning": "（LLMが生成した日本語の意味）",
  "example_1": "{\"en\":\"...\",\"ja\":\"...\",\"note\":\"\"}",
  "example_2": "{\"en\":\"...\",\"ja\":\"...\",\"note\":\"\"}",
  "memo": "（日本語の説明）",
  "line_user_id": "{{#開始.line_user_id#}}"
}
```

`example_1` / `example_2` は **JSON 文字列** で保存してください。`ja` がないとアプリに日本語訳が出ません。

## 4. 動作確認

1. LINE で英単語 `apple` を送信 → 例文に英語＋日本語訳
2. LINE で `りんごって英語で何？` を送信 → word=apple、意味・例文・説明が同じUI形式
3. Supabase の `example_1` を開き `ja` キーがあるか確認
4. 単語帳アプリで例文の下に日本語訳が表示されるか確認
